Put the two APKs here before zipping the module:

- `MiuiHome.apk` - the HyperOS 4 launcher (com.miui.home 8.01.02.9258) patched for HyperOS 3
- `HyperLauncherExt.apk` - the settings app (source: https://github.com/Mods-Center/HyperOS-Rust-Launcher-Mod/tree/main/HyperLauncherExt)

Then zip the *contents* of `magisk-module/` (not the folder itself). The ready-to-flash module is attached to the
GitHub releases.
